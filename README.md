# ATELIER

## Aplicación móvil para cotización y despiece de muebles

**ATELIER** es una aplicación móvil desarrollada con **Flutter y Dart**, orientada a facilitar el diseño, cálculo y cotización de muebles fabricados en melamina.

La aplicación permite automatizar el proceso de planificación de muebles, generando el despiece de piezas, estimando materiales necesarios y calculando costos para obtener un precio final de venta.

## Funcionalidades principales

- 📐 Registro de dimensiones del mueble.
- 🪚 Generación automática del despiece de piezas.
- 💰 Cálculo de costos de materiales.
- 📊 Cálculo del margen de ganancia.
- 🧾 Generación del precio final de venta.
- 📦 Detalle de materiales y piezas necesarias para la fabricación.

## Tecnologías utilizadas

- **Flutter**
- **Dart**
- **Android**

## Objetivo del proyecto

Facilitar el proceso de diseño, cotización y planificación de muebles de melamina, permitiendo obtener de manera rápida y precisa la información necesaria sobre materiales, costos y precio de venta.

## Aplicación

ATELIER fue desarrollada como un prototipo funcional para dispositivos Android, enfocada en mejorar y agilizar el proceso de cotización utilizado en la fabricación de muebles.
